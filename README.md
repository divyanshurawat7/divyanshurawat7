## 🚀 Featured Projects

### 🍳 [FlavoraX](https://github.com/divyanshurawat7/FlavoraX)
**AI recipe generator with voice control and a cooking assistant chat.**

- Generates recipes from dish names or raw ingredients using the **Groq API**
- Voice input/output support in **English and Hindi**
- Fetches real food images via the **Pexels API** and uses **Google OAuth** for secure login
- Built as a full-stack app with a **Python/Flask** backend and an HTML/CSS/JS frontend
- Technically interesting for combining an LLM-backed generation flow, multilingual voice I/O, and a conversational assistant in one product

`Python` `Flask` `Groq API` `Pexels API` `Google OAuth` `JavaScript`

---

### 🌾 [Agricultural Production Analysis](https://github.com/divyanshurawat7/Agricultural-Production-Analysis)
**Indian agricultural production analysis and crop yield prediction using Python.**

- Cleaned and preprocessed state/district/year-level crop production data (handling missing values, inconsistent headers, forward-filled fields)
- Performed exploratory data analysis: production trends, top-performing states, area-vs-production relationships, correlation heatmaps, and outlier detection
- Built a **Linear Regression** model to predict crop production from cultivated area and yield, evaluated with **R², MSE, and RMSE**
- Demonstrates the full data science workflow — from raw dataset to a working predictive model

`Python` `Pandas` `NumPy` `Matplotlib` `Seaborn` `Scikit-learn`

---

### ✈️ [Air Traffic Passenger Analysis Dashboard](https://github.com/divyanshurawat7/Air-Traffic-Passenger-Analysis-Dashboard)
**Interactive Power BI dashboard analyzing historical air passenger traffic.**

- Cleaned and transformed raw passenger data using **Power Query**
- Built DAX measures to compare airlines, regions, and domestic vs. international traffic
- Includes an interactive geographic map, year/airline filters, and regional distribution breakdowns (US, Asia, Europe, Middle East, and more)
- Shows applied business intelligence skills: data modeling, dashboard design, and insight generation

`Power BI` `Power Query` `DAX` `Data Visualization`

---

### 🎬 [Movie Analytics Dashboard](https://github.com/divyanshurawat7/Movie-Analytics-Dashboard)
**Power BI dashboard analyzing IMDb movie ratings, revenue, and budgets.**

- Multi-page dashboard covering Overview, Financial Analysis, Rating Analysis, and Insights
- Surfaces KPIs like highest revenue ($2.92B), average IMDb rating (6.46), and genre/language/country breakdowns
- Uses DAX-driven measures and interactive filters (release date, genre, country, language) for exploratory analysis
- Translates a raw movie dataset into concrete, decision-oriented recommendations

`Power BI` `Power Query` `DAX` `Business Intelligence`
