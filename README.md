## 🚀 Featured Projects

### 🤖 AI & Machine Learning

**[FlavoraX](https://github.com/divyanshurawat7/FlavoraX)** — AI Recipe Generator with Voice Control
An AI-powered recipe generation platform that creates recipes from dish names or ingredients, complete with real food images, voice input/output support in English and Hindi, and a conversational cooking assistant chat.
- **Built with:** Python, Flask, HTML5/CSS3/JavaScript, Groq API, Pexels API, Google OAuth
- **Highlights:** Secure Google login, multi-language voice interaction, dynamic food imagery pulled via API, LLM-driven recipe and chat generation
- **Why it's interesting:** Combines a Flask backend with an LLM API and multiple third-party services (auth, images, voice) into a single cohesive full-stack product

### 📊 Data Science & Analytics

**[Agricultural Production Analysis](https://github.com/divyanshurawat7/Agricultural-Production-Analysis)** — Crop Yield Analysis & Forecasting
Analyzes Indian agricultural production data across states, districts, and years to uncover production trends and build a predictive model for crop output.
- **Built with:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
- **Highlights:** Full data cleaning/preprocessing pipeline, exploratory data analysis (trend charts, correlation heatmaps, outlier detection via boxplots), and a Linear Regression model evaluated with R², MSE, and RMSE
- **Why it's interesting:** Demonstrates the complete data science workflow — from raw, inconsistent data to a working predictive model with quantified evaluation metrics

**[Air Traffic Passenger Analysis Dashboard](https://github.com/divyanshurawat7/Air-Traffic-Passenger-Analysis-Dashboard)** — Interactive Power BI Dashboard
Analyzes historical air passenger traffic to surface trends across airlines, regions, and years, comparing domestic vs. international travel patterns.
- **Built with:** Power BI, Power Query, DAX
- **Highlights:** Interactive geographic map visualization, year/airline slicers, KPI-driven insights on regional passenger distribution
- **Why it's interesting:** Shows practical BI skills — turning a raw CSV dataset into a polished, filterable business dashboard

**[Movie Analytics Dashboard](https://github.com/divyanshurawat7/Movie-Analytics-Dashboard)** — IMDb Data Analytics
A multi-page Power BI dashboard analyzing movie ratings, revenue, budgets, genres, languages, and countries from an IMDb dataset.
- **Built with:** Power BI, Power Query, DAX
- **Highlights:** Dedicated Overview, Financial, Rating, and Insights pages; KPI cards for revenue/budget/rating metrics; genre and language-level breakdowns with data-backed recommendations
- **Why it's interesting:** Goes beyond visualization into insight generation — translating dashboard findings into concrete recommendations
